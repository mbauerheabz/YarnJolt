# YarnJolt

Orchestrates containerized workloads across cloud-based infrastructure, enabling real-time processing and auto-scaling within a distributed server cluster.

With YarnJolt, you get a lightweight tool that stays out of your way.

**What you get**

- Orchestrates containerized workloads across cloud-based
- infrastructure, enabling real-time processing and
- auto-scaling within a distributed server

- python

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/YarnJolt.git`
2. `cd YarnJolt`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
